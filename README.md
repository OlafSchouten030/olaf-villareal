# olaf-villareal

Persoonlijke promotiesite van Olaf Schouten voor de Fontys-studiereis naar Villarreal (januari 2027).

Statische site zonder build-stap: `index.html`, `styles.css`, `script.js` en afbeeldingen in `assets/`.

## Lokaal bekijken
Open `index.html` in je browser.

## Online zetten (Vercel)
Importeer deze repository in Vercel, kies framework preset "Other" en laat build command en output directory leeg.
